OLED & Joystick Hardware Diagnostic Checklist

1. Display Screen is Completely Black / Off

  • Verify I2C address in code: most 0.96" OLEDs use 0x3C, but some use 0x3D.
  • Ensure you pass SSD1306_SWITCHCAPVCC in setup to turn on internal charge pump.
  • Check for inverted VCC/GND labeling on cheap breakout boards! Swapping power pins will destroy the SSD1306 IC.

2. Joystick Cursor Moves Erratically or Inverted

  • Standard analog joysticks idle around ADC midpoint ~512 (or ~2048 on ESP32 12-bit ADC).
  • If moving UP scrolls DOWN, swap the thresholds in firmware or swap VRX/VRY wires.
  • Make sure to use INPUT_PULLUP on the SEL button pin since SW shorts to GND when pressed.

3. Required Arduino Libraries

Install these libraries via standard Arduino Library Manager (Ctrl+Shift+I):

  • Adafruit SSD1306 by Adafruit
  • Adafruit GFX Library by Adafruit
  • Wire (Built-in Arduino standard library)
